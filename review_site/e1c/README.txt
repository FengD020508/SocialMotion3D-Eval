SocialMotion3D E1c 人工盲评
===========================

使用方法
1. 请先完整解压 ZIP，不要直接在压缩包预览窗口中运行。
2. 双击 index.html，建议使用最新版 Microsoft Edge 或 Google Chrome。
3. 填写匿名评审代号并开始。评分会自动保存在当前浏览器中。
4. 完成后下载 CSV，并将 CSV 发回实验组织者；JSON 可作为完整备份。

注意
- 请勿查找或索取 blind_key.json；本评分包没有包含该文件。
- 不要修改 videos 目录结构，否则网页无法找到视频。
- 如果更换电脑或浏览器，本地进度不会自动迁移，请先导出当前结果。
- A/B 的真实方法身份只应在全部评分完成后由实验组织者统一揭盲。

评分边界
- 球形头部没有朝向信息，不评价 head yaw、LOS 或 FTT 的精细头部方向。
- 正常侧身、转身或横穿不自动等于“身体—轨迹失调”；只记录与参考不符且明显不自然的持续问题。
- 看不出差异时请使用“无明显差异/无法分辨”，不要强迫猜测。
